## 处理顺序

首轮先解决 OQ-01/OQ-02/OQ-09，并同步确认 OQ-04/OQ-05。其结果决定采集接口、主指标、采样承诺和系统行为。随后完成算法、存储和 UI 细化。

非功能指标暂缓量化是当前用户选择，本轮不将推荐值包装成硬性门槛。若后续要求证明“资源不会无限增长”，则需要对应预算或可检测的有界性标准。

## 风险与应对

| 风险 | 影响 | 当前应对方向 |
|---|---|---|
| 私有接口或传感器键随系统变化 | 指标失效或误标 | 适配层隔离、显式能力探测、机型／系统矩阵 |
| 相同语义由不同来源以不同单位返回 | 错误温度 | 按来源解码、保留原始值／单位证据 |
| 重试与高频调度叠加 | 队列增长、耗能与退出延迟 | 单通道有界调度与调用超时设计 |
| EMA 后再求 max | 丢失已采集峰值 | Raw 独立聚合 |
| 数据库清理受阻 | 磁盘增长 | 检查点、短事务、容量观测与失败策略 |
| 只看模拟测试或一个小时运行 | 错误宣称兼容与稳定 | 实机测试＋跨保留周期运行 |
| 文档中混入旧结论 | 后续实现错误 | 状态、来源、纠正记录及追踪校验 |
