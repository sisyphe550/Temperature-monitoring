# 标签化、校验、EMA、聚合与趋势

更新日期：2026-09-17。状态：算法方向已讨论；具体参数与边界仍有待定项。

## 分路原则

推荐采用：

```text
读取值 → 标签化 → 有效性校验 → Raw Ring Buffer
                               ├─ Raw 入库
                               ├─ EMA → 实时展示／EMA 入库
                               │        └─ 时间回归 → 趋势／趋势入库
                               └─ Raw 窗口聚合 → 1s → 10s → 1min 历史
```

v0.3 总体图将聚合放在 EMA 后，又要求保存原始峰值，这两者冲突。C03/C04 提出的修正是从 Raw 聚合 min/max。该修正保持“保留已采集峰值”的目的，待在详细设计评审中落实（OQ-06）。

## 标签化与有效性

基本字段为时间戳、传感器 ID、传感器类型、摄氏值。逐物理核心标识已删除；各温度来源使用sourceID保持隔离。建议保留来源和原始 key，让错误与数据能够回溯。

已讨论的无效输入包括 null、NaN、Infinity、接口读取失败和明确无效的编码。无效样本不进入 EMA、聚合或趋势。不能随意按统一温度范围过滤所有传感器；每类来源的无效哨兵值与合理边界需实测。重复温度值本身不是错误。

## EMA

使用真实时间差：

```text
alpha = 1 - exp(-dt / tau)
ema(t) = alpha * raw(t) + (1 - alpha) * ema(previous)
```

`dt` 是连续有效样本间的实际时间差；不使用采样设置值冒充实际间隔。`tau` 是平滑时间常数。切换档位不按固定点数改变滤波时间尺度。

| 对象 | 附件／讨论中的候选 tau | 状态 |
|---|---|---|
| CPU 主指标、已验证CPU温度来源 | 0.5 秒 | 推荐初值，未实测冻结 |
| SSD | 1～2 秒，后续例子取 2 秒 | 推荐范围 |
| Battery | 3～5 秒 | 推荐范围 |

首次样本如何初始化、发生大缺口后是否重置、异常时间差如何处理均待 OQ-06/OQ-08 细化。EMA 会引入显示滞后；菜单栏和实时数字需说明其显示的是平滑值。

## 峰值与历史聚合

每条聚合包含 min、max、avg、latest、count。窗口合并：

```text
merged.min = min(child.min)
merged.max = max(child.max)
merged.count = sum(child.count)
merged.avg = sum(child.avg * child.count) / merged.count
merged.latest = 时间上最后一个有效样本值
```

上述 avg 为**样本平均**，不能称为时间平均。切换采样频率后，高频阶段在样本平均中权重更大；若产品要表达时间平均，则需按有效覆盖时长加权，并定义缺口语义（OQ-06）。

设计基线为：1 秒窗口完成后生成 1 秒记录，十个连续子窗口生成 10 秒记录，六个 10 秒窗口生成 1 分钟记录。窗口边界、启动时不完整窗口、空窗口、晚到样本和重试后的幂等合并需进一步定义，不能无限等待缺失的子窗口。

峰值只能保留在已有有效 Raw 中出现的最大值。高频轮询也不能保证捕获两次测量之间的所有物理峰值。图形平滑不允许制造高于已记录最大值的虚假峰值。

## 趋势

推荐对最近固定时间窗口内 EMA 值进行线性回归：`temperature(t) = k * t + b`，斜率单位 °C/s。实现时将时间原点平移到窗口内，避免直接用大日历时间戳造成数值问题，这是本轮文档化的实现建议。

| 对象 | 附件候选趋势窗口 | 状态 |
|---|---|---|
| CPU温度来源／热区 | 3～5 秒 | 推荐范围 |
| CPU 主指标 | 5～10 秒 | 推荐范围 |
| SSD | 20～30 秒；示例取 30 秒 | 推荐范围 |
| Battery | 30～60 秒；示例取 60 秒 | 推荐范围 |

斜率正负可描述升降方向，但“稳定”的阈值、最小样本数、最小覆盖时长、触发频率没有冻结。不能自行写入一个未经确认的温度告警或趋势阈值。趋势不触发高温通知。

## 缺口、时钟和动态切换

- 使用真实时间；建议单调时钟用于 dt，日历时间用于展示和查询。
- 休眠、长时间接口不可用或暂停造成缺口时，曲线断开，趋势不能跨缺口拟合。
- 恢复后重新建立可用窗口；EMA 重置规则待定。
- 切换 CPU 档位时保留已有历史，新样本采用新周期；聚合按时间窗口，count 反映实际有效读数。
- 空窗口不能填充 0°C 或未经标记的上次值。以 Missing 记录还是省略记录，见 OQ-06。

## 算法触发草案

| 算法 | 触发 |
|---|---|
| 标签化／校验 | 读取返回后 |
| EMA | 新有效 Raw 到达 |
| Raw 峰值／一级聚合 | 有效 Raw 进入窗口，窗口结束时输出 |
| 高级聚合 | 依时间边界合并已经闭合的子窗口 |
| 趋势 | 满足窗口数据条件后按约定节奏输出 |
| TTL | 设计基线每 60 秒执行 |

## 派生 CPU 指标与失效语义（2026-09-17）

若 RC-01 通过，处理顺序为：同批固定成员的有效读数 → max → 主指标 EMA；不是先对各成员 EMA 再取 max。二者不同，测试必须区分。定义记录成员、计算规则和批次跨度；它只表示已覆盖区域的最高读数，不能称为全芯片真实峰值。

任一必需成员缺失时本批派生指标缺失，不默默改变集合。新来源／新定义版本、重新发现后身份不明、休眠恢复时建议开始新的连续段，首点初始化 EMA，趋势重新积累窗口；正常档位变化保持既有定义和实际 dt。普通间歇缺口的阈值仍待 OQ-06/OQ-08。

失败、上次有效缓存和补齐旧值均不进入新的 Raw/count。保留相同数值的成功读取，但在没有源更新时间时仍标新鲜度未知。设计依据见 [19 第5～6节](19-reference-informed-design.md)。
