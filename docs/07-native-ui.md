# 原生界面与展示规则

更新日期：2026-09-14。状态：界面功能已确认；视觉样式、刷新参数和部分交互待设计。

## 界面范围

| 界面 | 已确认内容 | 待定内容 |
|---|---|---|
| 菜单栏 | 图标与默认 CPU Package EMA 温度；摄氏度、一位小数 | Package 最终含义；宽度；图标；缺失时文案 |
| 点击弹出面板 | 各类硬件实时温度；透明／半透明信息面板 | 排版、尺寸、具体材质、交互 |
| 主窗口 | 实时温度、CPU 档位选择、柱状图、折线图、历史数据 | 默认时间范围、传感器筛选、窗口行为 |
| 错误界面 | 错误代码、重新启动应用的指示 | 确认方式、退出时机、报告打开／导出入口 |

不包含高温通知、登录后自动启动开关或 Web 页面。UI 视觉规范仍需独立讨论，当前未生成视觉稿。

## 数据来源

| 元素 | 计算来源 | 承载路径 |
|---|---|---|
| 菜单栏 | 主 CPU 指标 EMA | 推荐实时展示模型 |
| 实时数字 | 对应传感器 EMA | 推荐实时展示模型 |
| 柱状图 | 各传感器 EMA | 推荐实时展示模型 |
| 最近 5 分钟实时折线 | EMA | v0.3 指定 `ema_samples`；C04 推荐内存路径，承载位置见 OQ-04 |
| 更长范围历史曲线 | 聚合 avg 与 max 信息 | SQLite 查询服务 |
| 峰值信息 | 已取得的有效 Raw | Raw 聚合结果 |
| 趋势 | EMA 时间窗口回归 | 趋势服务 |

用户后续明确采用加工后数据，覆盖附件中“数字直接 Raw、菜单栏取整数”的旧建议。不能恢复旧方案。

## 历史层级

| 查询最近时间范围 | v0.3 查询基线 |
|---|---|
| 不超过 5 分钟 | EMA |
| 超过 5 分钟至 1 小时 | 1 秒聚合 |
| 超过 1 小时至 24 小时 | 10 秒聚合 |
| 超过 24 小时至 72 小时 | 1 分钟聚合 |

用户指定任意过去起止时间时，不能仅按“跨度长度”选择已过期的细粒度层。例如查询两天前的一分钟，只能使用当时仍保留的分钟级记录。是否允许任意历史区间以及跨层拼接见 OQ-12。

## 显示真实性

- 保留一位小数是格式，不是 ±0.1°C 测量准确度声明。
- 缓存允许展示，但需显示数据暂未更新状态；过期判断阈值待定。
- 无数据和读取失败不显示 0°C 作为替代温度。
- 曲线对休眠等缺口断开；不以插值制造不存在的峰值。
- CPU 平均值／最大值若作为派生主指标，必须显示相符名称与说明；暂不能强行标作物理 Package。
- 图表保留 max 信息；具体采用辅助线、范围带或提示信息待视觉设计。

## UI 技术建议

SwiftUI 负责主窗口、表单和布局，Swift Charts 负责图表。AppKit 可用 `NSStatusItem` 控制菜单栏、`NSPopover` 控制弹出面板，通过 `NSHostingView/Controller` 嵌入 SwiftUI。`NSVisualEffectView` 提供半透明材质。

透明效果需尊重系统外观与辅助功能设置，不承诺所有系统设置下视觉完全一致。[AppKit 集成](https://developer.apple.com/documentation/swiftui/appkit-integration)、[NSVisualEffectView](https://developer.apple.com/documentation/appkit/nsvisualeffectview)

附件建议 UI 最大刷新 5～10 Hz、图表返回几百至 2000 点，均为推荐参数，不是用户冻结的验收上限。主窗口关闭、菜单栏仍运行、退出整个应用等生命周期需要分别定义（OQ-12）。
