## 被替代或纠正的内容

| 原讨论内容 | 当前处理 | 原因 |
|---|---|---|
| 全部 Apple Silicon Mac | 改为 Apple Silicon MacBook Air | 用户缩小范围 |
| Docker 数据库 | 删除 | 用户选择 SQLite 并明确删除 Docker |
| 数字显示 Raw、菜单栏只显示整数 | 不作为当前规则 | 用户后续选择加工后数据及一位小数 |
| 高频 Raw 不入库 | 改为短期入库 | 用户要求 Raw 与加工结果都保存 |
| 登录自启动 | 删除 | 用户明确取消 |
| 高温告警 | 删除；峰值分析保留 | 用户明确不设计告警 |
| CPU Package／Core 已存在确定公开映射 | 不成立 | 指标是目标，传感器语义和完整性未验证 |
| `IOPSKeys.h` 没有 Temperature key | **事实错误，已纠正** | Apple 头文件与本机 macOS 15.5 SDK 含 `kIOPSTemperatureKey` |
| 发现温度字段即可保证 M4 返回数据 | 不成立 | 接口声明与实机服务能力不同 |
| 50 ms 轮询保证 20 Hz 新硬件测量 | 不成立 | 请求间隔、源刷新与调度时延不同 |
| 一位小数意味着 ±0.1°C 准确度 | 不成立 | 显示格式与测量准确度不同 |
| EMA 后聚合即可保留 Raw 峰值 | 需要改为 Raw 分路聚合 | 平滑已经改变峰值；见 OQ-06 |
| count 加权必然等于时间平均 | 不成立 | 它计算样本平均；变采样率下时间权重不同 |
| 72 小时 TTL 就是磁盘体积上限 | 不成立 | 文件空闲页、WAL、索引、日志均影响空间 |
| 任何退出都能立即删除数据库 | 不成立 | 强杀／断电无法保证执行清理；下次启动补偿 |
| macOS 最新版固定为旧讨论中的 26.6.2 | 不沿用为当前事实 | 本轮未重新核实最新版，发布冻结时查询官方记录 |
| macOS 27 电池属性反馈等于官方删除公告 | 不采用此推断 | 原讨论论坛反馈不足以形成官方兼容契约 |
| `./data/monitor.db` 是正式 App 必须使用的路径 | 仅保留开发示例 | 正式可写目录待设计 |
| 创建目录就表示选择 Go | 不成立 | 当前语言建议为 Swift；路径与技术选择无关 |

## 未被本轮擅自决定的变更

1. 单项传感器不支持时继续运行还是退出。
2. CPU Package 是否正式改名为 CPU 平均／最高温度。
3. 逐核心不可实现时如何缩小产品承诺。
4. 教师数据库链路与实时内存路径如何验收。
5. 原需求中非功能指标暂缓量化的决定没有被改为具体 CPU／内存／能耗指标。

这些事项进入 [待决策清单](16-open-questions.md)，不得因整理文档而当作用户已经确认。
